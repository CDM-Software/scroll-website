# ScRoll — сайт продукта

Промо-сайт платформы для настольных ролевых игр **ScRoll**.

## Документы

- [docs/PRODUCT-CONTEXT.md](docs/PRODUCT-CONTEXT.md) — полный продуктовый
  контекст: что за продукт, аудитория, реальные фичи, ценности, терминология,
  предлагаемая структура страниц.
- [docs/DESIGN-MODEL.md](docs/DESIGN-MODEL.md) — дизайн-модель: палитра,
  типографика и правила, извлечённые из дизайн-системы приложения. Сайт обязан
  выглядеть как продолжение приложения.

## Процесс

Страницы дизайнятся в Claude Design на основе двух документов выше, затем
синхронизируются в этот репозиторий. Технологический стек сайта — TBD
(статик; кандидаты: Astro / Next.js static export).

## Связанные репозитории

- [CDM-Software/ScRoll](https://github.com/CDM-Software/ScRoll) — монорепо
  продукта (backend + mobile). Дизайн-токены сайта производны от
  `mobile/src/theme/` и должны обновляться при его изменениях.
