# ScRoll — продуктовый контекст для сайта

Полный контекст продукта для дизайна и контента промо-сайта. Источники:
требования платформы, глоссарий, реальный функционал мобильного приложения
(Expo/React Native, iOS + Android).

## 1. Что такое ScRoll

**ScRoll** — платформа для настольных ролевых игр (НРИ / TTRPG): поиск игр,
организация сессий, коммуникация и сообщество для игроков и мастеров.
Объединяет игроков и мастеров подземелий в единую экосистему: находи кампанию,
подавай заявку, общайся в чате партии и играй — из любой точки мира.

> Ребрендинг 2026: прежние названия Circle of DMs / CDMS / «Платформа Круга»
> НЕ используются в пользовательских текстах. Только **ScRoll**.

**Миссия:** сделать качественные настольные ролевые игры доступными каждому —
с проверенными мастерами, честными рейтингами и живым сообществом.

## 2. Аудитория

1. **Игроки** — хотят легко находить качественные игры под свой вкус (система,
   жанр, формат, цена), без географических ограничений. Боль: найти хорошего
   мастера и не нарваться на сорванную кампанию.
2. **Мастера (DM)** — хотят аудиторию, инструменты организации и (в будущем)
   монетизацию своих игр. Боль: сбор группы, недоверие новых игроков.
3. Клубы и сообщества НРИ — цифровое пространство для кампаний.

Язык аудитории: RU-first (сайт на русском; EN — later). Тон: тёплый, гиковский,
уважительный к культуре D&D, без кринжа и канцелярита. Слова сообщества
уместны (кампания, ваншот, мастер, партия, бросок), но текст понятен новичку.

## 3. Что уже умеет продукт (реальные фичи приложения)

### Для игроков
- **Лента игр и событий**: поиск по системе (D&D 5e, Cyberpunk RED),
  жанру (приключение, детектив...), формату (ваншот / кампания), цене,
  дате; фильтры + бесплатные игры; отметка «подходит новичкам».
- **Заявки на игры**: подать → мастер одобряет → ты в партии; вейтлист, если
  мест нет; статусы заявки в реальном времени.
- **События**: лекции, конкурсы, встречи сообщества — с участием и обсуждениями.
- **Чаты**: личные и групповые чаты партии (real-time, WebSocket), чат игры
  создаётся автоматически.
- **Друзья и профили**: заявки в друзья, профили с рейтингом, статистикой игр
  и временем в ScRoll.
- **Рейтинги**: оценки 1–5 и отзывы после игр — доверие строится на реальном опыте.
- **Новости и гайды**: редакционный контент — новости платформы и обучающие
  гайды по НРИ (с оценками полезности).
- **Пуши и уведомления**: заявка принята, место освободилось, новое сообщение.

### Для мастеров
- Создание и публикация игр (черновик → модерация → публикация).
- Управление заявками игроков (одобрение, вейтлист).
- Профиль мастера с рейтингом и отзывами; верификация мастеров платформой.
- Создание событий.

### Платформа
- Регистрация: email + OTP-код или Google-аккаунт.
- Модерация игр и мастеров — контроль качества контента.
- Поддержка (тикеты с диалогом), FAQ, благотворительные сборы (донаты).

### Скоро (roadmap, для секции «Что дальше» — формулировать осторожно)
- Геймификация: ранги (Неофит → Хранитель → ... → Архидруид), ачивки, баджи,
  лидерборды, квесты.
- Монетизация игр: оплата сессий, скидки за предоплату.
- Подписки на мастеров и рекомендации.

## 4. Ключевые ценности (для value-блоков сайта)

| Направление | Формулировка |
|---|---|
| География | Играй из любой точки мира — гибкое расписание, любые часовые пояса |
| Качество | Модерация мастеров и игр, честные рейтинги после сессий |
| Доверие | Верифицированные мастера, отзывы реальных игроков |
| Простота | Нашёл → подал заявку → играешь. Фильтры по системе, жанру, цене |
| Сообщество | Чаты партий, друзья, события, гайды для новичков |

## 5. Терминология (обязательно к соблюдению)

| Используем | Не используем |

| ScRoll | Circle of DMs, CDMS, «Платформа Круга» |
| Мастер / Dungeon Master | ГМ (это другая роль в системе) |

| Игра, кампания, ваншот | сессия (ок как синоним встречи) |
| Заявка на игру | бронирование |

## 6. Структура сайта (предложение, одна страница + возможные подстраницы)

1. **Hero**: слоган + подзаголовок + CTA «Скачать в Google Play» (+ App Store,
   когда появится) + мокап приложения (тёмный телефон с лентой игр).
   Варианты слогана (нужен выбор/итерация):
   - «Твоя следующая кампания начинается здесь»
   - «Найди свою партию. Своди свою партию»
   - «Настольные ролевые игры — из любой точки мира»
2. **Как это работает** — 3 шага (найди игру → подай заявку → играй) с
   скриншотами реальных экранов.
3. **Для игроков** — фичи-карточки (лента/фильтры, заявки, чаты, рейтинги).
4. **Для мастеров** — создание игр, управление заявками, репутация,
   (тизер монетизации).
5. **Доверие и качество** — модерация, верификация, рейтинги.
6. **Сообщество/контент** — события, гайды, новости.
7. **Что дальше** — roadmap-тизер (ранги, ачивки) для ощущения живого продукта.
8. **FAQ** — 5-6 вопросов (это бесплатно? как стать мастером? какие системы? ...).
9. **Footer**: соцсети, поддержка, политика/условия (circleofdms.com домен
   пока рабочий), © ScRoll.
