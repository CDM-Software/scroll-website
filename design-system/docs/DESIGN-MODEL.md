# ScRoll — дизайн-модель сайта

Токены извлечены из реального дизайна приложения (Figma `BTno6C78parGBMVxcQNXqm`
→ `mobile/src/theme/`). Сайт должен ощущаться как то же самое, что скачает
пользователь — тот же тёмный мир, тот же зелёный акцент, та же типографика.

## 1. Настроение и направление

- **Тёмный по умолчанию** (dark-first, светлой темы у продукта нет).
- Современный продуктовый минимализм уровня Linear/Vercel-лендингов +
  тёплый гиковский флейвор НРИ: кости, карты, свитки, магическое свечение —
  **акцентами**, не обоями. Никакого лубочного фэнтези, пергаментов и
  готических шрифтов.
- Глубина через слои чёрного и мягкое зелёное свечение (у таб-бара приложения
  есть green glow — фирменный приём, можно переиспользовать в hero).
- Скриншоты приложения — главный визуальный контент: настоящие тёмные экраны
  в мокапах телефонов.

## 3. Типографика

- **Шрифт: Geist** (sans), `Geist Mono` для акцентов-цифр/кода. Это шрифт
  приложения — обязателен для целостности бренда.
- Шкала приложения (для сайта масштабировать вверх, пропорции сохранить):
  h1 32/bold · h2 28/semibold · h3 24/semibold · h4 20/medium ·
  body 16/regular · small 14 · mini 12.
- Для веба hero-заголовок 56–72px, но с теми же весами (bold ≤ 700, без black).
- Межстрочные — просторные; текст на тёмном не жирнить сверх меры.

## 4. Форма и компоненты

- Радиусы: карточки 16px, контролы/кнопки 8–12px, чипы — full-round pill.
- Кнопки: primary — green-700 фон + белый текст; secondary — surface.base +
  граница #404040; на hover — лёгкое высветление, без теней-подушек.
- Карточки игр (референс из приложения): обложка сверху, бейдж жанра,
  название, дата зелёным акцентом, цена/статус — использовать этот же образ
  в фиче-блоках сайта.
- Иконки: lucide (как в приложении), тонкие, 1.5–2px stroke.
- Разделители секций — тонкие линии #27272a, не «карточные» тени.

## 5. Motion

- Сдержанно: fade+rise при скролле (16–24px, 300–400ms, ease-out), glow
  пульсация только в hero. Никаких паралакс-цирков.
- Мокапы телефона могут медленно «дышать» (scale 1.00→1.02).

## 6. Правила

1. Ни одного цвета вне палитры §2 (кроме фото/скриншотов).
2. Зелёный — единственный акцент. Бейджи-цвета только для меток контента.
3. Тёмный фон всегда; текст ≥ 4.5:1 контраст.
4. Скриншоты — только настоящие экраны приложения, не рисованные фейки.
5. Копирайт — на русском, тон из PRODUCT-CONTEXT §2, термины из §5.
6. Адаптив: mobile-first (аудитория мобильная), largest breakpoint 1200px
   контентная колонка.

## 7. Референсы направления

- linear.app — ритм секций, глубина тёмного.
- vercel.com — типографика, сдержанность.
- resend.com — тёмный + один акцент, glow.
- Из мира НРИ: dndbeyond.com — как НЕ надо (перегруз); startplaying.games —
  конкурент, полезно посмотреть структуру, сделать чище и темнее.
